# Work in Progress — portrait App Preview

The finished preview includes the app's existing `Introduction.mp4` playing
inside the actual introduction screen, followed by the portrait library,
Video Creator, and playback of a video created with the simulator's 51 local
example photos. All imagery is recorded app content; no generated UI or faces
are used in this video.

## Deliverables

- `work-in-progress-app-preview.mp4`: 29.4 seconds, portrait 886 × 1920,
  constant 30 fps, H.264 High Profile Level 4.0, Rec. 709, approximately 33 MB.
- `poster.png`: a frame extracted at 15.0 seconds. Select this time in
  App Store Connect's poster-frame editor; the PNG is provided as a reference.
- `manifest.json`: source edit points, technical metadata, and validation.
- `Review/contact-sheet.jpg`: visual overview of the edit.

The MP4 has a silent stereo AAC track at 48 kHz, so it works silently throughout.
It uses a 10 Mbps target video bitrate, 12 Mbps maximum, and web-friendly MP4
fast-start metadata.

## Edit

| Time | Content |
| --- | --- |
| 0–17.0 s | Introduction with the portrait time-lapse, app name, and existing tagline |
| 16.8–22.0 s | Real library footage with a slow scroll |
| 21.8–25.6 s | Open the Video Creator screen |
| 25.4–29.4 s | Playback of the portrait video generated by the app |

Scene boundaries use short 0.2-second dissolves. Launch/loading footage and
the export wait are omitted. The recording shows the app's existing copy and
controls, without additional caption overlays. The final playback's black
letterboxing is part of the real app player.

## Capture and reproducibility

Captured on 18 October 2026 using the booted **iPhone 18 Pro** simulator and
XcodeBuildMCP's video recording and UI controls. The simulator status bar was
temporarily set to 9:41 and restored after capture. The app's introduction was
enabled through a launch argument; a normal launch was restored afterward.

The selected source recordings remain locally in `Sources/`. This directory's
MP4 recordings are ignored by Git because they contain personal example media
and are larger than the final edit. To regenerate with Python 3 and FFmpeg:

```sh
python3 AppStore/AppPreview/render_preview.py
```

The render script checks source durations, then checks the final dimensions,
duration, constant frame rate, codecs, audio channels, file size, and full
audio/video decoding. Visual checks cover the contact sheet and scene boundaries.

## Upload

Upload the MP4 under **App Previews and Screenshots** for the matching iPhone
display size. Select the poster frame at **15.0 seconds**. These files are
prepared locally; they have not been uploaded or submitted to Apple.

Apple's accepted app-preview resolution differs from the simulator's native
1206 × 2622 capture. The edit scales proportionally and crops only a few pixels
to reach the accepted 886 × 1920 portrait resolution.
